🚀 Quick Start

1

Get Bot Token

Open Telegram, search @BotFather, send /newbot

2

Clone Repository

git clone https://github.com/nyxnoe/simple-telegram-bot.git

3

Install Dependencies

pip install -r requirements.txt

4

Configure & Run

cp .env.example .env && python bot.py
